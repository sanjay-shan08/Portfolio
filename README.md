# 3D Interactive Portfolio

A modern, immersive, and interactive 3D portfolio built with React, Three.js (React Three Fiber), and Vite.

## 🚀 Features

- **3D Graphics & Environments**: Powered by `three.js` and `@react-three/fiber`.
- **Advanced Post-Processing**: Utilizing `@react-three/postprocessing` for visual effects.
- **Smooth Animations**: Integrated `framer-motion` and `animejs` for fluid UI and component animations.
- **Rich Icons**: Featuring `lucide-react` and `react-icons`.
- **Fast Development**: Built on top of Vite for lightning-fast HMR and optimized builds.
- **Linting**: Preconfigured with `oxlint` for rapid linting.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Bundler**: Vite
- **3D Rendering**: Three.js, React Three Fiber, React Three Drei
- **Animations**: Framer Motion, Anime.js
- **Icons**: Lucide React, React Icons
- **Linting**: Oxlint
